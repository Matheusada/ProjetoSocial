<h2>📘 Descrição do Projeto</h2>

<p>O objetivo deste projeto foi criar um site simples e elegante que redireciona os visitantes para as minhas redes sociais. Com um design responsivo, o site se adapta a diferentes dispositivos e tamanhos de tela, garantindo uma experiência visual agradável. Além de ser um projeto de apresentação pessoal, o site foi construído com foco em um layout limpo e navegação intuitiva.</p>

<h3>🎯 Objetivo</h3>

<p>O objetivo principal do site foi:</p>

<ul>
  <li>Praticar a construção de páginas web responsivas com HTML5, CSS3 e JavaScript.</li>
  <li>Facilitar o acesso dos visitantes às minhas redes sociais, como Instagram e Facebook.</li>
  <li>Desenvolver um design elegante e moderno, com animações e interatividade.</li>
</ul>

<h2>🚀 Funcionalidades</h2>

<ul>
  <li>Links de redirecionamento para as redes sociais (Instagram, Facebook, etc.).</li>
  <li>Design responsivo, adaptável para dispositivos móveis, tablets e desktops.</li>
  <li>Estilização com CSS3, incluindo animações e efeitos de hover.</li>
  <li>Interatividade com JavaScript para melhorar a experiência do usuário.</li>
</ul>

<h2>🛠️ Tecnologias Utilizadas</h2>

<ul>
  <li><strong>Linguagens:</strong> HTML5, CSS3 </li>
  <li><strong>Design Responsivo:</strong> Flexbox, Grid Layout, Media Queries</li>
  <li><strong>Animações:</strong> CSS Transitions e JavaScript</li>
</ul>

<h2>🖥️ Exemplo de Uso</h2>

<p>Ao abrir o site, os usuários verão uma página com botões estilizados que redirecionam para suas redes sociais como Instagram e Facebook. O design é completamente responsivo, adaptando-se automaticamente a qualquer dispositivo, com transições suaves e um layout visualmente atraente.</p>
